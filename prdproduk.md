### Produk 9 — API Key DeepSeek ("Unlimited")

**Platform:** DeepSeek (platform.deepseek.com)
**Harga resmi:** Model **pay-per-token**, BUKAN unlimited resmi.
- DeepSeek V4 Flash: ~$0.14 /1J input (cache miss), $0.28 /1J output.
- DeepSeek V4 Pro: ~$1.74 /1J input, $3.48 /1J output.
- Cache hit hemat hingga ~90%. User baru dapat 5 juta token gratis saat registrasi.

**4 Benefit Utama:**
1. Salah satu API paling murah di pasar — hingga 99% lebih murah dari GPT-5.5.
2. Context window 1M token + max output 384K token (V4).
3. Mode thinking & non-thinking tersedia di kedua tier.
4. Context caching otomatis menekan biaya untuk prompt berulang.

> **Disclaimer "Unlimited":** DeepSeek tidak menjual paket unlimited. Penawaran "unlimited" hanya layak jika reseller membatasi rate atau menanggung risiko biaya token. Sebaiknya dijual sebagai **kredit/top-up bersaldo**, bukan unlimited murni.

### Produk 10 — API OpenAI ("Unlimited")

**Platform:** OpenAI (platform.openai.com)
**Harga resmi:** Model **pay-per-token**, BUKAN unlimited resmi.
- GPT-5.5 (flagship): $5 /1J input, $30 /1J output (cached input $0.50).
- GPT-5.4: $2.50 /1J input, $15 /1J output (workhorse hemat).
- GPT-5.4 Nano: $0.20 /1J input, $1.25 /1J output (ultra-budget).

**4 Benefit Utama:**

2. Context window hingga 1.05M token di GPT-5.5.
3. Cached input diskon hingga 90% (hemat besar untuk system prompt berulang).
4. Batch API hemat 50% input & output untuk task asinkron.

> **Disclaimer "Unlimited":** Sama seperti DeepSeek — tidak ada paket unlimited resmi. Risiko biaya menanggung di sisi reseller. Disarankan dijual sebagai **API key bersaldo / kredit terbatas**.

## 3. Catatan Strategi Penjualan

1. **Subscription (produk 1–8, 11):** punya harga tetap resmi → mudah dihitung margin reseller.
2. **API (produk 9–10):** TIDAK ada harga unlimited resmi. Jual sebagai **saldo/kredit** agar tidak rugi.
3. **Harga sering berubah** — Google Ultra baru turun 60% (I/O 2026), ChatGPT Pro tambah tier $100, DeepSeek sering revisi. Selalu re-verify sebelum listing.
4. **Promo & trial resmi** (Gemini 1 bulan gratis, DeepSeek 5J token gratis, Kiro trial 500 kredit) bisa jadi nilai tambah penawaran.
5. Sertakan **disclaimer harga & kurs** di landing page agar tidak ada salah ekspektasi pembeli.
